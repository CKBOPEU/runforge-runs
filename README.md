# Runforge Runs

Небольшой интерфейс мониторинга запусков агентных рабочих окружений. Это самостоятельный frontend-прототип без backend и авторизации: данные берутся из `src/data.ts` через асинхронный mock-сервис.

## Запуск

```bash
npm install
npm run dev
```

Проверки: `npm run test`, production-сборка: `npm run build`. Зависимости установлены. Проверка TypeScript, production-сборка и 5 автоматических тестов успешно выполнены. В среде Codex инструменты запускались напрямую через Node; стандартные npm-команды указаны для обычного окружения.

Для демонстрации ошибки откройте `/?error=1`: первый запрос покажет ошибку, кнопка **Try again** повторит запрос без ошибки.

## Что есть

- поиск по названию запуска и репозиторию без учёта регистра;
- фильтры по queued/running/succeeded/failed;
- асинхронная загрузка с loading/error/retry;
- панель подробностей с логами и результатом, закрытие кнопкой, кликом по фону или Escape;
- адаптивная компоновка для узких экранов.


## Структура
- `src/App.tsx` — состояние страницы, загрузка, поиск и выбранный запуск.
- `src/types.ts` — тип запуска и допустимые статусы.
- `src/data.ts` — восемь демонстрационных запусков.
- `src/mockService.ts` — Promise с задержкой; реального API нет.
- `src/components/FilterBar.tsx` — ввод поиска и кнопки статусов.
- `src/components/RunList.tsx` — таблица и пустой результат со сбросом.
- `src/components/RunDetails.tsx` — логи, результат, закрытие и клавиатурный фокус.
- `src/App.test.tsx` — пять тестов сценариев.
- `LEARNING_RU.md` — пояснения для разбора реализации.

## Проверка адаптивности
На узком экране таблица прокручивается по горизонтали внутри своего контейнера. Макет не требует горизонтальной прокрутки всей страницы. Поддерживаемая минимальная ширина — 360 px. Даты форматируются через Intl в часовом поясе браузера.

Бонусы сортировки и сохранения фильтров в URL не реализованы. Публикация демо и отправка репозитория выполняются отдельно после согласования.
